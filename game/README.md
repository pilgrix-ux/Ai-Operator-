# AI Operator — 3D Shooter

Original 3D mobile shooter inspired by the accessibility and fast match loop of Pixel Shooter, with original gameplay, art direction, maps, characters, and systems.

## Foundation roadmap

1. Playable third-person character controller
2. Mobile touch controls
3. Shooting, health, damage, reload and respawn
4. Bot combat
5. First arena map
6. Match state and scoring
7. Weapon/character progression
8. Multiplayer networking
9. Friends, rooms and matchmaking
10. Live-service content pipeline

## Design principles

- Mobile-first performance
- Fast time-to-fun
- Stylized original 3D art
- Fair progression; no pay-to-win combat advantages
- Systems separated so multiplayer and live content can be added without rewriting the core
