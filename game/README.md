# Cursed Clash — Godot Game

This folder is a standalone Godot project designed to be copied/imported from Android storage.

## Current battle prototype
- 3v3 team combat
- Player + AI fighters
- Original stick-fighter visual language
- Responsive movement, jump, dash and combo attacks
- Mana and ultimate system
- Charge-up, hit, skill and ultimate VFX
- Screen impact / hit-stop hooks
- Mobile touch controls plus keyboard testing
- Dark supernatural arena

## Reference direction
The gameplay target is the fast 3v3, skill-heavy, cursed-energy arcade feel of *Stickman Cursed Fight 3v3*, while all characters, names, art and effects in this project are original.

## Android import
Copy this `game` directory to device storage. In Godot Android choose Import and select the folder containing `project.godot`.
