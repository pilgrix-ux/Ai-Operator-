# Core Combat Loop

## Match

- 4v4 team match target
- Short 5–7 minute sessions
- Fast respawn
- First prototype can run with bots only

## Player

- Third-person camera
- Left thumb movement stick
- Right thumb aim/look
- Contextual fire/reload/ability buttons
- Aim assist tuned for touch without removing skill
- Sprint and dodge/slide planned after the basic loop

## Starter loadout

- Pulse Rifle: reliable automatic weapon
- Sidearm: fast fallback weapon
- Frag grenade: area denial

## Combat feedback

Every shot should communicate hit/miss, damage, elimination and reload state through animation, audio, particles and HUD feedback.

## Progression

Combat power stays skill-based. Unlocks focus on cosmetics, sidegrades and clearly balanced equipment rather than paid stat advantages.
